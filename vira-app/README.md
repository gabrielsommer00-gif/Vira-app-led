# VIRA APP

Plataforma de captação de clientes, organização de projetos e preparação de briefings para criação de sites e aplicativos.

## Independência Estrutural

Este diretório (`/vira-app/`) contém um projeto totalmente independente, com suas próprias configurações de TypeScript, Vite, Tailwind CSS v4, dependências e preparação de backend Express.

- Porta padrão de desenvolvimento/preview: `3001` (evitando conflito com a porta `3000`).
- Nenhuma configuração ou dependência da raiz é compartilhada ou importada.

## Scripts

```bash
npm install
npm run typecheck
npm run build
npm run dev
```
